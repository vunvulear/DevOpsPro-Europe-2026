# Golden Path Spec

This folder holds the spec-driven artifacts for the conference talk
**"Platform Engineering in 30 Minutes: Build a Golden Path, Not a PowerPoint"**.

Expected files (created via Spec Kit slash commands during the demo):

- `spec.md` — what the golden path delivers (created by `/speckit.specify`)
- `plan.md` — how it will be built (created by `/speckit.plan`)
- `tasks.md` — actionable, ordered tasks (created by `/speckit.tasks`)

Run the demo prompts in `prompts/` in order to populate this folder live.
