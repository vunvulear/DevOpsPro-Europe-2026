Using:

`specs/golden-path/spec.md`
`specs/golden-path/plan.md`

Create:

`specs/golden-path/tasks.md`

Break the work into small tasks that can be implemented and reviewed independently.

Use this format for each task:

- Task ID
- Title
- Description
- Files changed
- Acceptance criteria
- Demo notes

Include tasks for:
- CI workflow
- test execution
- dependency caching
- security workflow
- secret scanning
- Terraform folder structure
- Azure App Service Terraform resources
- Terraform validation workflow
- deployment workflow
- post-deployment smoke tests
- platform policies
- cost awareness
- operational readiness docs
- README update
- demo flow documentation

Also mark each task as one of:
- safe to do live
- better prepared before the session
- fallback branch recommended
